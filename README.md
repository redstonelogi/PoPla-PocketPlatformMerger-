# PocketPlatformMerger
## What it is
PocketPlatformMerger is a tool for the PocketPlatformer game builder from l0bster2.
In PocketPlatformer you can create games with own tiles (textures) in a user friendly interface, a bit like bloxels.
In PocketPlatformMerger you can select two or more games to Merge them into one game so for example if you have 3 Games, game one has 2 levels, game 2 has 3 levels and game 3 has 5 levels, you get one big game with 10 levels, from all the levels.

## How it works
You open the index.html file in a browser, select multiple games that are saved as the .html format and click Merge.
Beware of the Order how you select the games !

## Metroidvania merger (BETA by l0bster2)
Open `metroidvania/index.html` to merge two or more PocketPlatformer Metroidvania HTML games. Their positioned rooms are combined into one world. Each game's goal flag routes to the next game's start room, and the final game's goal routes to the ending screen.
